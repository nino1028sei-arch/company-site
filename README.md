# my_KANRIBU

企業サイト（コーポレートサイト）の静的 Web ページです。

## 概要

会社の基本情報を社外に向けて紹介するための Web サイトです。
HTML / CSS で作る静的サイトのため、サーバーやビルドツールがなくてもブラウザだけで表示できます。

掲載する内容の例:

- トップページ（会社のキャッチコピー・メインビジュアル）
- 会社概要（社名・所在地・設立年・代表者など）
- 事業内容・サービス紹介
- お知らせ・ニュース
- お問い合わせ

## ファイル構成

```
my_KANRIBU/
├── index.html   # トップページ
└── README.md
```

## ブラウザで index.html を開く手順

### 方法 1：エクスプローラーから開く

1. エクスプローラーで `C:\Users\nino1\projects\my_KANRIBU` を開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Microsoft Edge や Google Chrome など）でページが表示されます。

別のブラウザで開きたいときは、`index.html` を右クリックして
「プログラムから開く」から使いたいブラウザを選んでください。

### 方法 2：PowerShell から開く

```powershell
cd C:\Users\nino1\projects\my_KANRIBU
start index.html
```

### 方法 3：ブラウザに直接ドラッグ＆ドロップする

開いているブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても表示できます。

### 表示を更新するには

`index.html` を編集したあとは、ブラウザで `F5` キー（または `Ctrl + R`）を押して再読み込みしてください。
